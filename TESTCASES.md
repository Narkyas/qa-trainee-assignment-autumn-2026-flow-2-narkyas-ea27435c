# 7. Сквозной E2E-сценарий

## TC-28 — Полный жизненный цикл объявления

**Предусловия:** отсутствуют.

**Шаги:**
1. Зарегистрировать нового пользователя.
2. Авторизовать пользователя.
3. Получить Bearer-токен.
4. Создать объявление.
5. Получить объявление по ID.
6. Проверить данные объявления.
7. Получить список объявлений продавца.
8. Получить статистику объявления.
9. Проверить значения статистики.
10. Удалить объявление.
11. Повторно получить объявление.

**Ожидаемый результат:**
- регистрация успешна;
- авторизация успешна;
- Bearer-токен получен;
- объявление успешно создано;
- данные объявления соответствуют данным создания;
- объявление присутствует в списке продавца;
- статистика соответствует данным объявления;
- объявление успешно удалено;
- после удаления GET возвращает HTTP `404`.

**Автоматизация:** `test_full_item_lifecycle`
